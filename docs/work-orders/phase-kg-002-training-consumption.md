# Phase KG-002：训练与学情消费

## 开工定义

1. 用户问题：把已经审核发布的教学知识图谱接入训练、评价证据和教师学情，而非停留在展示层。
2. 范围内功能：正式 Neo4j、全 20 关 DSL、版本绑定、Agent 上下文、渐进脚手架、学习证据、教师洞察/回放、Cytoscape.js 教学投影。
3. 明确不做：学生全局图谱、三维可视化、复杂图算法、自动本体演化和在线图谱编辑。
4. 涉及模块：`knowledge_graph`、`training`、`teacher_analytics`、学生训练 feature、教师 dashboard/student-detail/knowledge-graph feature。
5. 数据和 API：新增 Attempt 图谱绑定、脚手架交互和逐轮图谱证据；新增学生脚手架事件、教师图谱与学情接口。
6. 组件拆分：训练脚手架、教师洞察、回放证据、图谱画布和图谱浏览器各自独立。
7. 验收标准：真实 Neo4j 发布与读取、学生提示使用可恢复、教师能追溯证据、全课程数据达到数量要求、完整质量门槛通过。
8. 风险与回滚：新版本隔离写入后再激活；失败保留上一版；旧 Attempt 固定版本；数据库可降回 Alembic `0007`。

## 完成记录

- 教师 DSL 已扩展至全部 20 关：20 案例、40 现象、80 策略、80 个唯一知识资源、80 脚手架、60 量规、40 结果；编译结果为 439 节点、440 关系、0 冲突。
- Neo4j 使用固定 5.26 LTS Community 镜像和官方 Python Driver；节点按 `graph_version + stable_key` 建复合唯一约束，发布在独立版本内事务写入后切换活动版本。
- Attempt 创建时绑定图谱版本；场景 Agent 仅获取局面信息，对话 Agent 获取隐藏策略与资源上下文。
- 学生端支持渐进展开与“已采用”记录，使用客户端事件 ID 保证幂等；旧 Attempt 不随新发布漂移。
- 每轮评价后生成图谱学习证据，教师班级/学生洞察和回放均可消费；学情按班级课程版本隔离。
- 教师图谱仅投影现象、知识资源和策略战术，避免把内部治理节点堆给教师。

- 全量真实 Neo4j API 冒烟：通过，教师投影 200 节点、160 关系。
- 浏览器：教师图谱 40/80/80 节点分类可见；班级学情与主统计均为 4 次完成训练、平均 80.6；学生“应对虚盘”脚手架展开与采用状态均成功。
- 课程版本隔离回归测试：当前班级只统计当前 `course_version_id`，历史版本同名小节不再重复。
