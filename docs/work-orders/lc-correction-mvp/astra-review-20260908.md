# 6-1 二次验收与修复（2026-09-08）

结论：此前整体验收结论过早。确定性训练闭环已存在，但不能将自动化通过等同于全部产品与发布验收通过。仍属 Milestone 2。

## 本次发现并修复

1. **课程版本切换导致进度表面归零。** 示例班被切到 beta.23，而课程路线只读该版本下的 ProgressRecord / Attempt。实际 beta.22 仍有12项完成记录。现按同一课程内未变的 unit key、版本、模式、模板、量规、提示词和先修关系投影历史状态；保留原 Attempt ID 与原版本绑定，不伪造新的完成记录。改版6-1不继承旧文本审阅完成状态。创建训练时的先修判断采用相同兼容规则。
2. **信用证排版不符合单证阅读体验。** 替换松散字段卡片为有边框的 Tag / Field / Details 表格，增加通知副本抬头、信用证编号栏、长条款分项及末尾标记；原信用证仍不可编辑。
3. **合同侧栏直接展示内部教学设定。** 改成按主体、价款、装运、期限、单据分组的公开事实简报，不展示“考查哪个字段”等内部编写说明。
4. **桌面编辑区离开视线。** 固定侧栏并允许独立滚动，隐藏桌面重复标签导航。保留所有原 field/item ID 与保存接口。
