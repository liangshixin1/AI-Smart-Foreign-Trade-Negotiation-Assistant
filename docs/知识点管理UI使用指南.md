# 知识点管理Web UI使用指南

## 概述

本系统为教师提供了完整的Web界面来管理外贸谈判知识图谱，支持知识点的增删改查、Excel批量导入导出、前置依赖和关联关系管理等功能。

## 功能特性

### ✅ 已实现的完整功能

#### 1. 知识点可视化管理
- **知识图谱总览**：基于Neo4j的可视化图谱展示
- **知识点列表**：展示所有知识点，支持实时搜索和多维度过滤
- **详细信息面板**：点击节点查看关联的知识点、关卡和理论课程

#### 2. CRUD完整操作
- **创建知识点**：填写名称、分类、描述、难度等信息
- **编辑知识点**：更新现有知识点的所有属性
- **删除知识点**：支持安全删除（带确认）
- **查看详情**：展示知识点的完整信息

#### 3. Excel批量管理
- **下载模板**：一键下载标准Excel模板
- **批量导入**：支持.xlsx、.xls、.csv格式
- **批量导出**：导出所有知识点为Excel文件
- **导入反馈**：显示创建、更新、失败的数量统计

#### 4. 搜索和过滤
- **实时搜索**：按知识点名称搜索
- **分类过滤**：按知识分类筛选
- **难度过滤**：按初级/中级/高级筛选
- **组合过滤**：支持多个条件同时使用

#### 5. 关系管理
- **前置依赖**：设置必须先掌握的知识点
- **关联关系**：建立相关知识点的连接
- **可视化关系**：在图谱中展示依赖和关联

## 使用教程

### 一、访问知识点管理界面

1. 使用教师账号登录系统
2. 点击顶部导航栏的 **"知识图谱"** 标签页
3. 页面分为三个主要区域：
   - **上方**：知识图谱可视化 + 知识点索引
   - **中间**：Excel批量管理工具栏
   - **下方**：知识点列表 + 编辑表单

### 二、创建新知识点

#### 方法1：手动创建

1. 在左侧知识点列表区域，点击 **"+ 新增"** 按钮
2. 右侧将显示创建表单，填写以下信息：

   **必填字段：**
   - 知识点名称（例：FOB术语）

   **可选字段：**
   - 分类：从下拉列表选择或留空
   - 描述：简要说明知识点内容
   - 难度级别：初级/中级/高级
   - 重要程度：低/中/高/核心
   - 学习时长：预计学习分钟数
   - 标签：用逗号分隔（例：贸易术语, 价格条款, 国际贸易）
   - 详细内容：完整的知识点说明

3. 设置前置依赖（可选）：
   - 点击 **"+ 添加"** 按钮
   - 从弹出对话框选择必须先掌握的知识点
   - 可添加多个前置依赖

4. 设置关联关系（可选）：
   - 点击 **"+ 添加"** 按钮
   - 选择相关的知识点
   - 可添加多个关联

5. 点击 **"保存知识点"** 按钮完成创建

#### 方法2：Excel批量创建

1. 点击 **"下载模板"** 按钮获取标准Excel模板
2. 在Excel中填写知识点信息（按模板格式）
3. 点击 **"导入Excel"** 按钮
4. 选择填好的Excel文件
5. 等待导入完成，查看结果统计

### 三、编辑知识点

1. 在左侧列表中点击要编辑的知识点
2. 右侧将显示该知识点的完整信息
3. 修改任何字段
4. 点击 **"保存知识点"** 按钮更新

### 四、删除知识点

1. 点击列表中的知识点进入编辑模式
2. 点击右上角的 **"删除"** 按钮
3. 在确认对话框中点击"确定"

⚠️ **注意**：删除操作不可恢复，请谨慎操作

### 五、搜索和过滤

#### 使用搜索框
- 在搜索框中输入知识点名称的任意部分
- 列表将实时显示匹配的结果

#### 使用过滤器
- **分类过滤**：选择特定分类，只显示该分类的知识点
- **难度过滤**：选择难度级别，只显示对应难度的知识点
- **组合使用**：可同时使用搜索和多个过滤器

### 六、Excel批量操作

#### 导入知识点

1. **准备Excel文件**
   - 下载模板：点击 **"下载模板"** 按钮
   - 按照模板格式填写数据
   - 必填列：name（知识点名称）
   - 可选列：category, description, difficulty, importance等

2. **执行导入**
   - 点击 **"导入Excel"** 按钮
   - 选择准备好的Excel文件（支持.xlsx/.xls/.csv）
   - 系统将自动处理导入

3. **查看结果**
   - 导入完成后，工具栏下方显示统计信息
   - 成功创建数量
   - 成功更新数量（如果名称已存在）
   - 失败数量

#### 导出知识点

1. 点击 **"导出Excel"** 按钮
2. 系统自动下载包含所有知识点的Excel文件
3. 文件名格式：`knowledge_points_YYYY-MM-DD.xlsx`

### 七、管理前置依赖和关联

#### 添加前置依赖

前置依赖表示学习当前知识点前需要先掌握的知识点。

1. 进入知识点编辑模式
2. 在 **"前置依赖知识点"** 区域点击 **"+ 添加"**
3. 在弹出对话框中输入前置知识点名称
4. 点击确定添加
5. 点击保存按钮应用更改

#### 添加关联关系

关联关系表示与当前知识点相关的其他知识点。

1. 进入知识点编辑模式
2. 在 **"关联知识点"** 区域点击 **"+ 添加"**
3. 在弹出对话框中输入关联知识点名称
4. 点击确定添加
5. 点击保存按钮应用更改

#### 移除依赖或关联

- 点击已添加的依赖/关联标签上的 **"✕"** 按钮
- 点击保存按钮应用更改

### 八、知识图谱可视化

在页面顶部的知识图谱总览区域：

- **查看图谱**：自动加载并显示完整的知识图谱
- **刷新图谱**：点击 **"刷新图谱"** 按钮重新加载
- **拖拽节点**：用鼠标拖动节点调整位置
- **缩放视图**：使用鼠标滚轮缩放
- **点击节点**：查看节点详情和关联信息

## API端点列表

前端调用的所有API端点：

### 知识点管理（7个）
```
GET  /api/graph/knowledge-points/enhanced - 获取知识点列表（支持过滤）
GET  /api/graph/knowledge-points/<name>   - 获取单个知识点详情
POST /api/graph/knowledge-points           - 创建新知识点
PUT  /api/graph/knowledge-points/<name>   - 更新知识点
DELETE /api/graph/knowledge-points/<name> - 删除知识点
POST /api/graph/knowledge-points/<name>/prerequisites - 添加前置依赖
POST /api/graph/knowledge-points/<name>/relations - 添加关联关系
```

### 分类管理（2个）
```
GET /api/graph/categories      - 获取所有分类
GET /api/graph/categories/tree - 获取分类树结构
```

### Excel导入导出（4个）
```
GET  /api/graph/import/template - 下载Excel模板
POST /api/graph/import/excel    - Excel导入
POST /api/graph/import/csv      - CSV导入
GET  /api/graph/export/excel    - Excel导出
```

## 常见问题

### Q1: 为什么无法创建重复名称的知识点？
A: 知识点名称是唯一标识符，系统不允许重复。如果需要更新已存在的知识点，请使用编辑功能。

### Q2: Excel导入失败怎么办？
A:
1. 确保使用了最新的模板
2. 检查必填字段（name）是否填写
3. 确认数据格式正确
4. 查看导入状态消息了解具体错误

### Q3: 如何批量修改知识点？
A:
1. 使用Excel导出功能导出所有数据
2. 在Excel中编辑
3. 使用Excel导入功能更新（系统会自动识别更新）

### Q4: 前置依赖和关联有什么区别？
A:
- **前置依赖**：有顺序要求，必须先掌握前置知识点
- **关联关系**：无顺序要求，表示相关但不必须先学

### Q5: 知识图谱加载很慢怎么办？
A:
1. 点击"刷新图谱"按钮重新加载
2. 检查网络连接
3. 确认Neo4j数据库正常运行

## 最佳实践

### 1. 知识点命名
- 使用清晰、简洁的名称
- 避免过长的名称
- 使用专业术语
- 示例：✅ "FOB术语" / ❌ "关于FOB贸易术语的详细介绍"

### 2. 分类管理
- 建立清晰的分类体系
- 避免分类过多或过细
- 保持分类的一致性
- 示例分类：贸易术语、价格条款、支付方式、物流运输等

### 3. 标签使用
- 使用多个相关标签提高可搜索性
- 标签应该简短（2-4个字）
- 使用逗号分隔
- 示例：贸易术语, 价格, FOB, 国际贸易

### 4. 前置依赖设置
- 只设置直接的、必须的前置依赖
- 避免循环依赖
- 保持依赖链清晰
- 示例：学习"CIF术语"前需要先掌握"FOB术语"

### 5. Excel批量操作
- 导入前先备份现有数据（使用导出功能）
- 分批导入大量数据（建议每批不超过100条）
- 导入后及时检查数据准确性
