# 📖 智能知识图谱批量导入使用指南

> **适用人群**：老师、教务人员（无需技术背景）
> **功能简介**：通过Excel表格一次性导入知识点、关系和案例，快速构建完整的知识图谱

---

## 🎯 核心优势

与传统Excel导入相比，智能批量导入有以下特点：

| 特性 | 传统Excel导入 | 智能批量导入 ✨ |
|------|-------------|--------------|
| **导入内容** | 只能导入知识点节点 | 知识点 + 关系 + 案例 |
| **ID管理** | 需要手动填写ID | 自动生成，无需填写 |
| **关系定义** | 需要调用API手动创建 | Excel中直接填写，自动创建 |
| **表达方式** | 技术性术语 | 自然语言（必须先学、建议同时学） |
| **错误提示** | 普通错误信息 | 智能推荐相似名称 |
| **数据验证** | 需手动检查 | Excel内置下拉菜单 + 预校验 |

## 📋 使用步骤

### 第一步：下载智能模板

1. 登录系统，进入「知识图谱管理」页面
2. 找到「✨ 智能批量导入（推荐）」区域
3. 点击「下载智能模板」按钮
4. 下载后得到一个Excel文件，包含以下内容：
   - **知识点主表** - 填写知识点和关系
   - **案例库表** - 填写案例数据（可选）
   - **使用说明** - 详细的填写指南

### 第二步：填写Excel表格

#### 表1：知识点主表（必填）

**字段说明：**

| 列名 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 章节 | ⚪ | 所属章节 | 第一章 询盘 |
| 知识点名称 | ✅ | 唯一的名称 | 询盘基本流程 |
| 知识点类型 | ⚪ | 从下拉菜单选择 | 技能型 |
| 难度 | ⚪ | 初级/中级/高级 | 初级 |
| 重要性 | ⚪ | 必修/推荐/选修 | 必修 |
| 预计学时(分钟) | ⚪ | 数字 | 30 |
| 内容简介 | ⚪ | 一句话描述 | 掌握询盘的基本流程 |
| 详细描述 | ⚪ | 详细说明 | 询盘是外贸业务的第一步... |
| 关键词 | ⚪ | 逗号分隔 | 询盘,业务流程,沟通 |
| **必须先学** | ⚪ | 填写知识点名称 | 外贸基础术语;国际贸易概念 |
| **建议同时学** | ⚪ | 填写知识点名称 | 询盘话术技巧 |
| **可对比学习** | ⚪ | 填写知识点名称 | FOB术语;CIF术语 |

**填写示例：**

```
章节：第一章 询盘
知识点名称：询盘基本流程
知识点类型：技能型
难度：初级
重要性：必修
预计学时：30
内容简介：掌握询盘的基本流程和注意事项
详细描述：询盘是外贸业务的第一步，包括客户背景调查、询盘接收...
关键词：询盘,业务流程,沟通
必须先学：（留空，表示这是基础知识）
建议同时学：询盘话术技巧
可对比学习：（留空）
```

**⚠️ 重要提示：**

1. **知识点名称必须唯一**，不能重复
2. **关系列（必须先学等）请复制粘贴知识点名称**，不要手打（避免错别字）
3. **多个知识点用分号分隔**，例如：`A;B;C`
4. 不需要的列可以留空

#### 表2：案例库表（可选）

如果您有实际案例、邮件模板、常见错误等示例数据，可以填写此表。

**字段说明：**

| 列名 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 关联知识点 | ✅ | 填写知识点名称 | 询盘基本流程 |
| 案例类型 | ✅ | 从下拉菜单选择 | 实际案例 |
| 案例标题 | ✅ | 简短标题 | 美国客户询盘实例 |
| 案例内容 | ✅ | 详细内容 | 客户询盘邮件：Dear... |
| 关联练习关卡 | ⚪ | 关卡号 | 6-1 |

**填写示例：**

```
关联知识点：询盘基本流程
案例类型：实际案例
案例标题：美国客户询盘实例
案例内容：【背景】美国客户通过展会获取我司联系方式...(详细内容)
关联练习关卡：6-1
```

**案例类型可选项：**
- 实际案例 - 真实业务场景
- 邮件模板 - 可复用的邮件范本
- 文档模板 - 合同、发票等模板
- 常见错误 - 典型错误案例及纠正
- 对话示例 - 谈判对话实录

### 第三步：检查数据（推荐）

1. 在系统中选择「知识点主表」文件（必填）
2. 如果有案例数据，选择「案例库表」文件（可选）
3. 点击「先检查数据」按钮
4. 系统会显示详细的校验结果：
   - ✅ **数据预览**：将导入多少知识点、关系、案例
   - ❌ **错误列表**：哪些地方有问题，如何修改
   - ⚠️ **警告信息**：可能的问题提示

**智能错误提示示例：**

```
❌ 错误：knowledge_points - 第15行 - 关系引用
  你写的 'CIF术语' 找不到
  💡 建议：你是不是想写：CIF价格术语, CIF成本构成
```

5. 如果有错误，**修正Excel后重新检查**，直到全部通过

### 第四步：正式导入

1. 确认数据无误后，点击「开始导入」按钮
2. 等待系统处理（通常几秒到几十秒）
3. 查看导入结果统计：

```
✅ 导入成功！

📊 导入统计
```

4. 刷新页面，查看新导入的知识图谱

## 💡 常见问题 (FAQ)

### Q1: 和上面的"Excel导入"有什么区别？

**A:** 主要区别如下：

- **传统Excel导入**：只能导入知识点节点本身，无法定义知识点之间的关系（如前置知识、对比关系等）。适合快速添加知识点。

- **智能批量导入**：一次性导入知识点 + 关系 + 案例，构建完整的知识图谱。适合批量构建整个课程体系。

### Q2: 如果我填错了知识点名称怎么办？

**A:** 系统会自动检测并推荐相似的名称。

例如，你在"必须先学"列填了`CIF术语`，但实际知识点叫`CIF价格术语`，系统会提示：

```
💡 建议：你是不是想写：CIF价格术语
```

直接复制正确的名称粘贴即可。

### Q3: 必须先学、建议同时学、可对比学习，有什么区别？

**A:** 这三个列代表不同的知识点关系：

- **必须先学**（prerequisite）：学习当前知识点前，必须先掌握的前置知识
  - 例如：学习"CIF价格计算"前，需要先学"CIF价格术语"

- **建议同时学**（similar）：相关的、建议一起学习的知识点
  - 例如：学习"询盘基本流程"时，建议同时学"询盘话术技巧"

- **可对比学习**（contrast）：可以对比理解的知识点
  - 例如：学习"FOB术语"时，可以对比"CIF术语"、"DDP术语"

### Q4: 如何填写多个知识点？

**A:** 用**英文分号**（`;`）分隔，例如：

```
必须先学：外贸基础术语;国际贸易概念;询盘基本流程
```

### Q5: 案例库表必须填吗？

**A:** 不是必须的！

- 如果暂时没有案例数据，只上传「知识点主表」即可
- 后续可以随时补充案例数据

### Q6: 能不能先导入一部分知识点，后面再补充关系？

**A:** 可以！

第一次导入时，关系列（必须先学等）可以留空，只导入知识点本身。后续整理好关系后，再次导入同一个Excel（包含关系列），系统会自动更新。

### Q7: 如果知识点已经存在怎么办？

**A:** 系统会**更新**已存在的知识点，不会重复创建。

例如，你第一次导入了50个知识点，后来发现其中5个需要修改描述，直接修改Excel后重新导入，系统会更新这5个，其他45个保持不变。

### Q8: 建议先检查还是直接导入？

**A:** **强烈建议先点"先检查数据"**！

原因：
- 提前发现错误，避免浪费时间
- 了解将导入多少数据
- 智能错误提示帮你快速定位问题

只需几秒钟，可以避免很多麻烦。

### Q9: 导入失败了怎么办？

**A:** 如果导入失败，系统会详细告诉你原因：

1. 查看错误列表，找到具体哪一行、哪个字段有问题
2. 根据建议修正Excel
3. 重新上传

常见错误：
- ❌ 知识点名称重复
- ❌ 引用的知识点不存在（关系列填错了名称）
- ❌ 枚举值错误（类型、难度填错了）

### Q10: 能导入多少条数据？

**A:** 理论上没有上限，但建议：

- 单次导入不超过**200个知识点**
- 如果数据量很大，分批导入（按章节分）
- 可以多次导入，系统会自动合并

## 🎯 最佳实践

### 1. 准备阶段

✅ **先整理知识点列表，再填写关系**

建议先在Excel中列出所有知识点名称，确保没有重复和错别字，然后再填写关系列。

✅ **使用复制粘贴，不要手动输入名称**

在填写"必须先学"等关系列时，从"知识点名称"列复制粘贴，避免手打导致的错别字。

### 2. 填写技巧

✅ **预计学时设置合理**

一般10-60分钟为宜。太短（<5分钟）或太长（>120分钟）都不利于学习规划。

✅ **关键词设置3-5个**

不要太多也不要太少。关键词用于搜索和推荐。

✅ **案例内容尽量详细**

好的案例能帮助学生理解抽象概念。建议包括：
- 背景说明
- 具体场景
- 处理步骤
- 注意事项

### 3. 导入流程

✅ **第一次导入建议分批**

- 先导入一个章节（10-20个知识点），测试流程
- 确认无误后，再导入全部数据

✅ **善用"先检查数据"功能**

每次导入前都先检查，可以避免90%的问题。

✅ **保留Excel文件备份**

导入成功的Excel文件建议保存，作为知识图谱的"源文件"，方便后续修改和更新。

### 4. 维护更新

✅ **增量更新**

如果只需要修改部分知识点，不需要重新导入全部数据。只需：
1. 在Excel中修改需要更新的行
2. 重新导入
3. 系统会自动识别并更新

✅ **定期补充关系**

知识图谱是动态的，可以随时补充新的关系：
1. 在Excel中找到对应知识点
2. 填写新的关系（必须先学、建议同时学等）
3. 重新导入

## 🔍 Excel模板结构详解

### 知识点主表的列说明

#### 基本信息列
- **章节**：帮助组织课程结构，不影响知识图谱
- **知识点名称**：唯一标识符，必须不重复
- **知识点类型**：便于分类和筛选

#### 学习属性列
- **难度**：初级（入门）→ 中级（进阶）→ 高级（深入）
- **重要性**：必修（核心知识）→ 推荐（建议学）→ 选修（扩展）
- **预计学时**：帮助学生规划学习时间

#### 内容描述列
- **内容简介**：显示在列表中，建议1句话（<50字）
- **详细描述**：完整的知识点说明，可以很长
- **关键词**：用于搜索和智能推荐

#### 关系定义列（核心）
- **必须先学**：定义学习路径的先后顺序
- **建议同时学**：形成知识点网络
- **可对比学习**：帮助学生辨析概念

### 案例库表的作用

案例库表是对知识点的补充说明，类型包括：

1. **实际案例**：真实业务场景，提供代入感
2. **邮件模板**：可直接复用的范本，实用性强
3. **文档模板**：标准格式的文档，如合同、发票
4. **常见错误**：典型错误及纠正，避免重复犯错
5. **对话示例**：谈判对话实录，学习沟通技巧
