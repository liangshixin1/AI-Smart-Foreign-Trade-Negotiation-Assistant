# 实施路线图：先交付可演示的教学闭环

## 总体策略

本周产品不追求“全自动构图”或“大而全图谱后台”，而是完成一条可信闭环：教师能写、系统能解释、专家能审核、学生训练能消费、教师学情能回看。所有阶段都保留关闭图谱功能并回退到现有课程配置的能力。

## Phase 0：设计冻结（0.5 天）

交付：

- 教师 DSL 1.0 字段、下拉词表、示例和填写说明。
- DSL 到内部图谱的映射矩阵。
- 阻断/警告/建议三级校验规则。
- 一个演示关卡与一个验收案例。

准入门槛：任课教师评审确认“看得懂、填得出、没有数据库语言”；课程专家确认七类教学概念足以表达目标案例。

## Phase 1：本周最小可演示闭环（Day 1–Day 3）

范围：

- 下载教师模板、上传 `.xlsx`、文件安全检查。
- 解析七张教学表，生成教师语言的校验报告。
- 生成只读“教学结构预览”：案例 → 局面 → 策略/知识 → 提示 → 评价 → 结果。
- 用确定性规则生成图谱变更草稿；新词和冲突标记为“待专家确认”。
- 技术员能批准或退回整个变更集，并发布到隔离的演示图谱版本。

明确不做：浏览器内可视化编辑器、自动教材抽取、复杂图算法、三维大图、全课程批量迁移。

DoD：示例工作簿可被解析；错误能定位到单元格；重复上传不重复建图；发布失败不影响现有训练。

## Phase 2：训练与学情消费（Day 3–Day 5）

选择“应对虚盘”作为纵向切片：

- 场景 Agent 读取案例背景和局面线索，但不泄露标准策略。
- 对话 Agent 可触发“虚盘限定语”局面，并依据学生是否澄清承诺推进回应。
- 评价 Agent 将每轮预审关联到量规维度和自查项。
- 学生卡住时按 1 级线索、2 级策略、3 级句框逐级提示，并记录使用情况。
- 教师回放显示学生在哪个局面使用了何种策略、是否依赖提示、结果和证据是什么。

DoD：一次真实训练从发布案例启动，图谱至少驱动一个提示、一个评价关联和一个教师薄弱点展示；关闭功能开关后仍能走原有训练流程。

## Phase 3：专家治理与批量扩展（下一迭代）

- 按项审核新增、复用、冲突和低置信度映射。
- 维护规范词、别名、概念类型和弃用关系。
- 变更影响分析、版本对比、回滚和审计导出。
- 将现有课程逐章迁移为 DSL；每批 3–5 个案例，通过校验和人工抽查后发布。

DoD：同一概念可跨案例复用而不重复；每条关系来源可追溯；旧课程版本可稳定复盘。

## Phase 4：教师体验与分析闭环

- 浏览器内向导式案例编辑器，仍沿用同一 DSL，不新造第二套模型。
- 教师从班级薄弱点反向定位到局面、策略、知识和可用脚手架。
- 支持复制案例、局部修改、导出 Excel 和重新导入。
- 大图仅用于专家展示整体覆盖、孤立概念和课程结构风险；学生端默认使用局部、任务导向视图。

## 任务依赖与责任

| 工作流 | 主责 | 协作 | 验收人 |
|---|---|---|---|
| DSL 与示例 | 产品/教学设计 | 任课教师 | 课程专家 |
| 解析与校验 | 后端 | 前端 | 技术负责人 |
| 语义编译 | 后端/知识工程 | 课程专家 | 技术负责人 |
| 审核界面 | 前端 | 后端 | 课程专家 |
| Neo4j 发布 | 后端/运维 | 知识工程 | 技术负责人 |
| 训练消费 | 训练模块负责人 | 教学设计 | 任课教师 |
| 学情展示 | 教师端负责人 | 评价模块 | 任课教师 |

## 风险与回滚

| 风险 | 早期信号 | 控制措施 | 回滚 |
|---|---|---|---|
| 模板仍然太复杂 | 教师频繁询问字段含义 | 可用性走查、减少必填、增加完整示例 | 冻结 1.0，延期非必要字段 |
| LLM 映射不稳定 | 相同输入产生不同关系 | 确定性规则优先、固定 prompt/version、人工审核 | 禁用 LLM 候选，只用词表精确匹配 |
| 概念重复污染图谱 | 同义项数量快速增长 | 别名词表、相似项提示、发布前合并 | 回滚变更集并修正词表 |
| Neo4j 发布失败 | 节点数或引用检查异常 | 新版本隔离写入、激活前校验 | 保持上一活动版本 |
| 图谱未产生教学价值 | 只展示大图，无训练消费 | 纵向切片必须驱动提示、评价和学情 | 关闭展示入口，回到教学闭环补齐 |
| 工期失控 | 专家后台需求膨胀 | 本周只做整包批准/退回和只读差异 | 高级逐项编辑进入下一迭代 |

## 本周演示脚本

1. 教师打开模板，修改“应对虚盘”案例的一条提示和一个评价维度。
2. 上传后系统指出一个故意设置的校验错误，并定位到具体单元格。
3. 修正后展示教学结构与自动生成的关系草稿。
4. 技术员批准并发布新的演示图谱版本。
5. 学生进入关卡，未识别限定语时收到一级提示；继续困难时收到二级提示。
6. 完成对话后，评价把表现关联到“承诺识别”和“请求实盘”维度。
7. 教师端打开回放，看到局面、策略证据、提示依赖和改进建议。
