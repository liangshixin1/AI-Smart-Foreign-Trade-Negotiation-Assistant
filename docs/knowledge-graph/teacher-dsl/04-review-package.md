# 评审文档：教师 DSL 与知识图谱三级架构

## 1. 评审目标

本次评审不讨论“大图是否酷炫”，只判断四件事：教师是否能维护、教学逻辑是否成立、系统映射是否可解释、发布治理是否安全。任一项不通过，都不应进入课程批量迁移。

## 2. 需要确认的关键决策

1. 教师模板是否以七类教学概念为边界，是否还需删减必填字段。
2. 任课教师只提交案例草稿，课程专家/技术员负责审核发布。
3. LLM 只提供候选映射，不能直接写入已发布图谱。
4. PostgreSQL 管任务、版本和审计；Neo4j 管已审定语义关系。
5. 学生端默认消费局部脚手架和反馈，不展示全量大图。
6. 本周只验证一个纵向切片，批量迁移后置。

## 3. 评审角色

| 角色 | 重点问题 | 建议人数 |
|---|---|---:|
| 一线任课教师 | 是否看得懂、填得出、愿意维护 | 3 |
| 外贸课程专家 | 局面—策略—知识—结果是否专业 | 2 |
| 二语教学专家 | 提示层级、撤除条件、评价证据是否合理 | 1 |
| 产品/交互 | 错误提示、预览和审核流程是否清晰 | 1 |
| 后端/知识工程 | 编译、版本、幂等、回滚是否可实现 | 2 |
| 测试/安全 | 文件安全、权限和失败恢复是否充分 | 1 |

## 4. 教师可用性评审

请让教师在无口头培训情况下完成：复制一个案例、增加一个关键局面、配置两条策略、补充一条分级提示、写一个评价维度并提交。

通过标准：

- 至少 2/3 教师在 30 分钟内完成。
- 不需要解释节点、关系、图数据库或内部 ID。
- 教师能说清每张表解决的教学问题。
- 必填项错误能根据提示独立修正。
- 教师认为模板比“节点表 + 关系表”更接近日常备课。

记录：完成时间、求助次数、误填字段、未理解术语、希望删除或增加的字段。

## 5. 教学设计评审

| 检查项 | 通过证据 | 阻断条件 |
|---|---|---|
| 成果对齐 | 核心成果可被评价维度覆盖 | 只写活动，没有可验证成果 |
| 局面真实性 | 学生可观察到明确线索 | 局面是抽象知识点而非商务事件 |
| 策略适切 | 有适用条件、行动和不建议做法 | 只有万能话术，没有决策条件 |
| 知识服务行动 | 每项知识说明与案例的关系 | 只是堆术语，与策略无关 |
| 脚手架递进 | 线索→策略→句框，且有撤除标准 | 直接给答案或永久提示 |
| 评价可证 | 维度有可观察证据和等级描述 | 只有总分或自由评语 |
| 结果分化 | 不同选择可能导向不同结果 | 结果与策略无条件关联 |
| 反思迁移 | 复盘问题能连接到后续训练 | 仅复述本轮答案 |

## 6. 图谱语义评审

- 每个自动生成对象都有来源锚点。
- 相同术语在不同案例中优先复用，不重复造点。
- “局面”“策略”“知识”“能力”“结果”语义边界清楚。
- 条件性关系保留条件，不把“可能导致”误写成必然因果。
- 新概念、同名异义、跨类型匹配必须进入人工确认。
- 删除采用弃用或版本替换，不破坏历史 Attempt 的复盘。

抽样方法：从变更集中随机抽 20 条关系，逐条核对教师单元格、编译规则和专家决定；要求 100% 可解释。

## 7. 工程与治理评审

| 领域 | 必须满足 |
|---|---|
| 权限 | 教师不能发布；专家只能审核授权课程；技术员操作留审计 |
| 幂等 | 同一文件哈希和模板版本重复上传不重复建图 |
| 版本 | 工作簿、DSL、编译器、词表、课程和图谱版本均可追溯 |
| 一致性 | 新图谱通过校验后再切换活动版本 |
| 回滚 | 发布失败或人工撤回时仍使用上一稳定版本 |
| 安全 | 禁用宏、公式执行和外部链接；限制文件大小与行数 |
| 可观测 | 记录导入耗时、错误类型、映射命中率、人工确认率、发布结果 |
| 隐私 | 不将学生对话或密钥写入图谱导入日志 |

## 8. 评分与准入门槛

每类 5 分，总分 25 分：教师可用性、教学有效性、语义可解释性、工程可靠性、治理与安全。

- 进入本周演示：总分至少 20，且无阻断项。
- 进入小范围试用：总分至少 22，教师可用性和教学有效性均至少 4。
- 进入全课程迁移：总分至少 23，连续两次发布与回滚演练通过。

任何以下问题均一票否决：教师模板暴露数据库模型；LLM 可跳过审核发布；关系无法追溯来源；发布失败影响现有训练；评价无法关联真实训练证据。

## 10. 建议评审结论措辞

“该方案已把知识图谱的专业复杂性从教师创作界面移至可治理的编译与审核层。教师通过教学案例语言表达情境、策略、知识、脚手架、评价与结果；系统负责生成可解释的图谱草稿；专家负责语义质量和发布。只有当图谱能实际驱动训练提示、结构化评价和教师学情诊断时，才视为产生教学价值。”
