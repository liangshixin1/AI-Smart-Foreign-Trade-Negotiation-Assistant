# 外贸谈判知识图谱：教师教学案例 DSL 评审包

## 结论

本方案不要求普通教师理解 Neo4j、节点、关系、Cypher 或内部 ID。教师只需用熟悉的教学设计语言描述一个案例：学生会遇到什么局面、应采取什么策略、需要哪些知识与材料、何时给予什么提示、怎样评价、可能形成什么结果。系统将 Excel 编译为可审查的图谱变更草稿，技术员与课程专家审核后发布。

三级架构为：

1. 教师简易模板：教学案例 DSL，负责表达教学意图。
2. 系统自动映射：校验、规范化、术语消歧、关系推导、变更预览。
3. 专家后台维护：处理新概念、低置信度映射、冲突、版本发布与回滚。

## 本次示例工作簿

工作簿包含“应对虚盘、价格还盘、信用证审核与改证、质量索赔”四个示例，覆盖谈判对话、单证审阅和商务邮件三种训练方式。示例来自现有课程 2.1.0，并被重写为教师可维护的教学案例，而不是 Neo4j 导入行。

## 关键设计边界

- Excel 是教师创作入口，不是数据库镜像。
- 教师填写的案例编号只用于跨表引用；内部实体 ID、别名和关系由系统生成。
- 确定性规则优先，LLM 只能提出候选映射，不能直接发布图谱。
- 每个自动生成的节点和关系都必须追溯到工作簿、工作表、行和字段。
- 导入只生成“草稿变更集”；审核通过后才成为已发布教学图谱。
- 学生侧消费的是教学服务结果，如提示、资源推荐和评价证据，不直接面对全量图谱。
