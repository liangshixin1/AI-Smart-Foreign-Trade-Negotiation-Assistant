# 外贸谈判公开体验版 v0.2.0

1. 下载公开版 setup.exe，以当前 Windows 用户安装。无需 Python、Node 或 Docker。
2. 首次打开填写自己的 DeepSeek API Key 和账户可用的模型名称。默认 deepseek-flash 可编辑。
3. 点击“测试连接”（可能产生少量 API 费用），成功后“保存并重启应用”。
4. 确认显示“DeepSeek 联网模型”，点击学生体验。可以浏览十阶段知识图谱，进行对话、评价与信用证练习。教师体验用于查看本机合成体验班。
5. 顶部“体验版 → 配置 AI / 更换 Key”可修改或删除 Key。保存或删除会重启，请先结束当前操作。

无 Key 时仅为明确标识的样例模式，不代表真实 AI 表现。真实请求及相关练习内容发送至 DeepSeek 官方接口，费用由你的账户承担。

Key 使用 Windows 当前账户的系统加密能力保存，不回显；更换系统账户或电脑后请重新配置。此保护不能防御同一系统账户下的全部恶意程序。

学习数据位于 %APPDATA%\ForeignTradePublic，卸载保留。可在卸载前从界面删除 Key；删除本机配置不等于在供应商平台撤销 Key。

本版本未签名，Windows 可能显示未知发布者。请从项目 GitHub Release 获取，核对 SHA-256。已验证 Windows ARM 上运行 x64，原生 x64 尚未独立验收。暂不提供自动更新。

报告问题时可附错误截图及“导出诊断”文件；不要上传 Key、ai-settings.enc、数据库或对话中的隐私信息。
