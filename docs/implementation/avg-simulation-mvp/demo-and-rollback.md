# AVG 仿真谈判 MVP 演示与回滚

## 五分钟专家演示

1. 启用 `SIMULATION_ENABLED=true`，登录已有先修资格的学生。
2. 在 `chapter-3-section-1` 准备页比较“对话模式 / 仿真模式”，选择仿真模式创建新 Attempt。
3. 展示公共事实驱动的 5 段简报：立即显示、下一句、跳过摘要和重看均不调用模型。
4. 在舞台输入一条有依据的英文还盘，展示 1—3 个短 beat、表情/轻动作以及“未读完先保留草稿”的控制。
5. 展开态势：说明 trust / willingness 是公开表达的局面估计，alignment 来自条款账本；打开本轮原话证据。
6. 打开学习支持、历史，再关闭，确认草稿和当前台词位置未丢失。
7. 刷新页面，确认 Message、Presentation、态势 revision 与草稿恢复且不重复生成。
8. 正式提交并查看模式适配评价；切换教师账号，回放完整短台词、分镜和态势证据。
9. 新建一个对话模式 Attempt，说明旧 IM 仍走原体验和统一教学证据链。

## 开关与安全降级

- 默认：`SIMULATION_ENABLED=false`。关闭后不允许新建仿真 Attempt；已存在仿真记录仍可读取和教师回放。
- 资产降级：表情失败 → neutral；全部立绘失败 → 同身份中性剪影；背景失败 → 纯色。
- 分析失败：台词保留，态势显示暂未更新；只重试分析，不重新生成台词。
- 简报失败：使用公共事实派生的规范摘要，不重写场景、不读取私有事实。

## 回滚步骤

1. 先将 `SIMULATION_ENABLED=false`，阻止新建仿真局。
2. 保留应用代码时，可让旧仿真记录继续只读；无需删表或删资产。
3. 若必须代码回滚，先备份数据库，再回退应用到支持 0016 的版本。
4. 只有确认不再需要任何 0017 仿真记录时，才执行 Alembic downgrade 到 `20260904_0016`；该动作会删除仿真会话、分镜、态势和创建幂等表，属于不可逆数据删除。
5. 浏览器资产目录可在关闭功能后保留；它不会被旧应用加载。不要用删除资产代替数据库/功能开关回滚。

## 恢复验证

- 开关关闭后：课程仅返回 chat 可选，新仿真创建被服务端拒绝。
- 旧 IM：仍可新建、发送、提交和评价。
- 旧仿真：学生/教师公共历史可读取，Message 仍是证据真值。
