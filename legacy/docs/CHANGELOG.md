# 变更日志

> 记录各版本的主要变更，便于快速了解开发历程。

## Beta 3 (开发中期) - 2025年1月

### 语义网络知识图谱
- **DAG风格架构** - 将知识图谱升级为有向无环图结构
- **心理语言学概念** - 引入语义网络理论，支持同族/同类/搭配关系
- **新增节点类型**：`SemanticClass`（语义类别）、`Slot`（槽位）
- **新增关系类型**：`IN_CLASS`、`FITS_SLOT`、`RELATED_TO`
- **知识点预计算** - 教师上传理论内容后自动预匹配，避免运行时负载
- **知识点召回优化** - 召回限制调整为5条，过滤不相关节点

### 词汇网功能 (新增)
- **`services/lexical_suggestion_service.py`** - 词汇建议核心服务
- **语气替换** - 提供柔和/强硬/中性的表达替代
- **思政元素** - Win-Win、诚信、尊严、合规导向建议
- **地道性替换** - 本地化表达推荐
- **上下文锚点** - 基于相关知识点的精准建议
- **向量召回+图谱融合** - 多路召回，按得分排序

### 语音交互系统 (新增)
- **`routes/asr.py`** - 语音识别路由
  - 文件上传转写 (`POST /api/asr/transcribe`)
  - WebSocket流式识别 (`WS /api/asr/stream`)
  - DashScope语音服务集成
  - PCM格式处理优化
- **`routes/tts.py`** - 语音合成路由
  - 文本转语音 (`POST /api/tts/synthesize`)
  - 多音色支持（Ryan、Cherry、Jennifer等）
  - 24kHz高质量音频
  - PCM转WAV格式转换
- **语音通话模式** - 手动发送、拖动操作、挂断功能

### AI辅助功能 (新增)
- **`routes/assistants.py`** - AI辅助路由
- **邮件助手** (`POST /api/ai/email/assist`)
  - 邮件草稿生成
  - 现有邮件润色
  - 场景上下文建议
- **聊天Copilot** (`POST /api/ai/chat/copilot`)
  - 实时聊天建议
  - 流式响应输出
  - 谈判策略推荐

### 实战练习界面
- **Review Mode** - 新增单证审查模式
- **界面重塑** - 接近真实阿里外贸软件体验
- **即时评估优化** - 评分与建议分离，SSE流式推送
- **知识点匹配** - 理论实践与知识图谱实时关联

### 知识点召回增强
- **`services/embedding_service.py`** - 多模型嵌入缓存服务
  - 支持多模型热切换
  - 懒加载机制
  - NaN/Inf向量清理
- **`services/reranker_service.py`** - 结果重排序服务
- **来源区分** - 前端标识AI识别 vs 关键字识别

### 教师工作台增强
- **知识标签标准化** - 统一处理不同格式的标签
- **学生状态判定** - 活跃/正常/不活跃/需关注
- **学习进度颜色标识** - 优秀(绿)/良好(蓝)/需提升(橙)/落后(红)
- **学生列表增强** - 筛选、排序、搜索功能
- **学习趋势图表** - 每周表现变化可视化
- **行为热点渲染** - 访问时间热力图
- **知识薄弱点分析** - 识别需加强的知识点

### 前端工程
- **`foreign-trade/`** - 新增 Vite + React 前端模板
- **移动端优化** - 优化移动端用户体验
- **知识图谱批量导入器** - 调整词汇项去重逻辑
- **管理端回归单体** - Beta 2 拆分的 `static/js/admin/` 8 模块在 Beta 3 开发中重新整合回单文件 `admin.js`（页面实际仅加载后者），未引用的模块文件已删除；后续模块化将通过 React 重构完成（见 `docs/前端重构计划.md`）
- **第三方库本地化** - Chart.js/marked/DOMPurify/Quill/ECharts/G6 从 CDN 改为本地托管（`static/vendor/`），锁定版本，消除供应链与断网风险

### 评估服务重构
- **`services/evaluation_service.py`** - 引入严格JSON输出
- **分数解析增强** - 容忍 ```json 包裹、回退正则
- **SSE流式评估** - 先推分数、后推详情
- **拆分函数** - `compute_score`、`compute_detail`、`build_evaluation_result`

### Bug修复
- 修正知识点匹配逻辑
- 修复若干前端交互问题
- 优化错误处理和日志记录

## Beta 2 - 2025年1月

### 知识图谱系统
- **Neo4j本地化** - 从云端Aura迁移到Docker本地部署（延迟<10ms）
- **知识点模型增强** - 从1个属性扩展到25+个属性
- **完整Web UI** - 13个REST API端点 + 可视化管理界面
- **Excel批量导入导出** - 支持一次性导入100+知识点
- **AntV G6可视化** - 替换ECharts，专业图谱渲染
- **三级知识分类体系** - 层级化的知识组织
- **关系管理** - 前置依赖(REQUIRES) + 关联(RELATES_TO)
- **Word教材解析** - 上传DOCX自动生成知识点草稿
- **DeepSeek精排** - AI驱动的知识点匹配
- **RAG轻量匹配** - 基于Token重叠的快速匹配

### 前端架构
- **模块化重构** - 管理端JavaScript拆分为8个独立文件
- **知识图谱UI** - `graph-knowledge.js` (56KB)
- **富文本编辑器** - 理论课时编辑器
- **学生端知识点展示** - 知识卡片与匹配

### 核心功能
- **10章关卡式训练** - 完整外贸流程覆盖
- **3档难度系统** - balanced/challenging/realistic
- **多模型协同** - 5个DeepSeek API Key隔离
- **流式对话** - SSE实时响应
- **作业管理** - 布置、追踪、导出
- **学生名册** - Excel批量导入

### 数据库
- **SQLite扩展** - 新增字段支持评估结果和会话元数据
- **Neo4j约束** - 唯一性约束和索引优化
