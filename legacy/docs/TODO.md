## 📌 配置说明

### Beta 3 新增环境变量
```bash
# DashScope语音服务
DASHSCOPE_API_KEY=sk-xxx

# 嵌入模型配置
EMBEDDING_MODEL_NAME=BAAI/bge-m3  # 或 EMBEDDING_MODEL=BAAI/bge-m3（兼容旧变量名）
EMBEDDING_CACHE_DIR=./models

# 词汇网配置
LEXICAL_VECTOR_THRESHOLD=0.7
LEXICAL_MAX_SUGGESTIONS=10

# 知识点召回配置
KP_RECALL_LIMIT=5
KP_RELEVANCE_THRESHOLD=0.6
```

### 硬件建议
```
Beta 3 推荐配置:
- CPU: 8核
- 内存: 16GB
- 磁盘: 50GB SSD
- GPU: 可选（加速嵌入计算）
```

| 优先级 | 标签 | 说明 |
|--------|------|------|
| P0 | 🔥 | 紧急且重要，影响核心功能 |
| P1 | ⚡ | 重要，显著提升用户体验 |

| P3 | 🌟 | Nice to have，长期愿景 |

## 📝 备注

1. **语音服务**：当前依赖DashScope，后续可考虑多服务商支持
2. **嵌入模型**：默认使用multilingual模型，中文场景可切换专用模型
3. **前端框架**：foreign-trade/模板为React新工程，当前主应用仍为Vanilla JS
4. **知识图谱**：Beta 3引入DAG架构，需注意循环依赖检测
